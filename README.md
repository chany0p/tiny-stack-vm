A tiny stack virtual machine for make.fun's [tiny-stack-vm-01 bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): one `main.ts` (Node 22, stdlib only) that answers every instance of a drawn set. 32-bit wrapping arithmetic, a 256-value stack, calls, 256 words of memory, input/output, all ten traps with their exact exit codes, and the step and output limits — verified 1,000,000/1,000,000 on the practice set and on fresh generator-drawn sets.
